bytes are retained. Exact URLs, UTC timestamps, descriptions and SHA-256 are in
`manifest.json`; sequence-derived hashes are in the validation output. Metadata
and downloadable representations can change even when a nucleotide accession
version remains the same, so both version and raw-file hashes are recorded.

não substitui os termos dos provedores. Consultar:

No source paper text is reproduced. GenBank FEATURES remain present in the raw
fixture for independent reference inspection, but BioForma imports ORIGIN only.
The bacterial example is a partial rRNA locus, not a complete bacterial genome.
The phage example is single-stranded DNA; the viewport is an idealized duplex.
Arbitrary-frame translation is a string operation, not annotation or proof of
protein expression. The structure is independent of the open sequence.
