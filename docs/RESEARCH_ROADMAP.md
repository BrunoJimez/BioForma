# BioForma — roteiro científico / research roadmap

## Estado atual / current state

BioForma 0.3 é uma bancada desktop didática, bilíngue e rastreável. Há evidências
computacionais medidas, registradas em `VALIDACAO.md` e `validacao/`. Não há
validação biológica, previsão de organismos, estudo com participantes, artigo
submetido ou DOI. “Programadores da vida” é uma visão de projeto, não um resultado
científico demonstrado pela versão atual.

BioForma 0.3 is a bilingual educational desktop workbench with provenance and
measured computational evidence. There is no biological validation, organism
prediction, participant study, submitted paper or DOI. The measured software
claims must remain separate from long-term project aspirations.

## Próximas etapas com critérios / next steps with criteria

| Etapa / stage | Trabalho / work | Evidência exigida / required evidence |
|---|---|---|
| Corpus externo / external corpus | Ampliar registros e formatos sem selecionar só resultados favoráveis | Amostra definida antes das medições, falhas reportadas, comparação independente |
| Anotações / annotations | GenBank FEATURES, coordenadas, orientação, códigos genéticos, sequências parciais | Concordância em corpus com casos join/complement, testes de limites e exceções |
| Escala / scale | Genomas completos e interface que não traduza o genoma como uma proteína | Medidas de memória, tempo e responsividade, sem cortes silenciosos |
| Contribuição científica / scientific contribution | Definir uma pergunta e comparação com ferramentas existentes | Métrica relevante, baseline, análise de incerteza e limites de generalização |
| Avaliação didática / educational evaluation | Medir compreensão de sequência/modelo e rastreabilidade | Protocolo prospectivo, instrumentos, amostragem e requisitos institucionais aplicáveis |
| Modelo biológico / biological model | Só se a pergunta exigir: escolher um sistema e dados experimentais adequados | Calibração separada de dados de teste, unidades físicas e validação fora da amostra |
| Artigo / paper | Relatar métodos, resultados reais e limitações | Dados e código reproduzíveis, revisão humana especializada, autoria responsável |

Nature e Science são ambições editoriais, sem garantia de adequação ou aceite.
Escolher o periódico depois de definir e demonstrar a contribuição. Uma interface
nova com testes de software, sozinha, não estabelece uma descoberta biológica.
Nature and Science are editorial ambitions, not promised outcomes. Journal
selection follows a demonstrated contribution, with claims supported by data.

## Depósito público futuro / future public deposit

Usar o GitHub para desenvolvimento e uma versão arquivada no Zenodo para código,
dados e resultados com identificador persistente. O Zenodo recebe materiais de
pesquisa, software e documentos; sua documentação está em
https://about.zenodo.org/ e https://help.zenodo.org/. O artigo/preprint deve refletir
um estudo realizado e pode ser depositado no repositório compatível com seu tema
e as políticas do periódico escolhido. Nenhum depósito foi feito nesta etapa.

Use GitHub for development and an archival repository such as Zenodo for a
versioned research package. A future deposit should include the exact source
commit, source-fixture manifest, protocol, full outputs including failed cases,
environment requirements, licenses/source attribution, and the study manuscript.
Mint and cite a DOI only after an actual deposit. Open deposition does not replace
peer review. No deposit has been performed in this stage.

Antes de submeter, verificar as políticas atuais de dados, código e declaração do
uso de IA do periódico. O autor humano confere os dados, interpreta os resultados
e assume responsabilidade pelo artigo. Não inserir ORCID, afiliação, aprovação
ética, financiamento ou DOI que não tenham sido confirmados.
